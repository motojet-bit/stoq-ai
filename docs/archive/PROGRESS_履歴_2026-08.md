### 2026-08-01 — Phase 2 Step 5.5: コントロール類のサイズ固定 ＆ ドロップ拒否（🚫）の解消 ✅
実機で見つかった Web 標準仕様の考慮漏れ 2 件を修正した。

1. **スライダー操作中のガタつきを解消**
   - 真因は `:root { font-size: var(--fs-base) }`。**`:root` の font-size は `rem` の基準**であり、
     Tailwind の余白・幅・高さはすべて `rem` で表現されている。
     そのため文字を大きくするとボタンやスライダーまで太り、
     **カーソルの下から要素が逃げて操作不能**になっていた
   - 指定を `:root` から `body` へ移動。これで `rem` の基準は 16px に固定されたまま、
     文字だけが継承でアプリ全域に連動する
   - さらに `.ui-fixed` を新設し、右上のコントロール群（AI設定ボタン ＋ フォント調整）を
     まとめて 12px 固定に。`FontSizeControl` の各部品も
     `h-[22px]` / `w-[72px]` / `h-[4px]` など**絶対値 px で完全固定**した
     （上の AI設定ボタンが太るとスライダーが下へずれるため、群ごと固定する必要がある）
2. **パネル D&D の進入禁止マーク（🚫）を解消**
   - HTML5 Drag and Drop は、ドロップ先が **`dragenter` と `dragover` の両方で
     `preventDefault()` を呼ばない限りブラウザ既定の拒否が働く**。
     従来は `dragover` のみ、しかも MIME 種別の判定を通ったときだけ打ち消していた
   - 判定を挟まず必ず打ち消すように変更し、`onDragEnter` も追加
   - `dragstart` で `text/plain` にも同じ値を入れ、カスタム MIME を落とす環境でも成立させた
   - `dragleave` は `relatedTarget` が子要素なら無視し、枠のちらつきを止めた
- **検証**: `npm run verify` ✅ / `cargo test --lib` ✅（フロント 64 件 / Rust 35 件）

### 2026-08-01 — Phase 2 Step 5.4: IBKR 風の操作感へ修正（リサイズ・パネル移動・フォント全域） ✅
IBKR のトレーディングツールを参考にした 5 要件を実装した。

1. **ドラッグリサイズの方向反転と非固定化（最優先）**
   - 原因は符号ではなく**どちらのペインに実サイズを持たせるか**だった。
     従来は 2 番目を固定していたため 1 番目が `flex-1` になり、
     **中身が空（ティッカー未入力）のとき 1 番目が 0 まで潰れて仕切り線を掴めなかった**
   - `splitMath.ts` を `clampSecondSize` → `clampFirstSize` + `desiredFirstSize` に作り替え、
     **1 番目に px を与えて 2 番目に残りを割り当てる**方式へ変更。
     仕切り線がポインタ位置そのものになるため、
     「下へ引く＝上の市場データが広がる / 上へ引く＝下の対話が広がる」が直感どおりになった
   - `ResizeObserver` を追加。**ウィンドウを縮めても固定 px が残らず**、
     常に両ペインの最小サイズを満たす範囲へ入れ直す
   - 当たり判定を 1px → 5px（`-top-2 h-5`）に拡大し、`pointercancel` でも確実に離す
   - `.panel` の `height: 100%` を `flex: 1 1 0%` に変更し、CSS の固定高を撤廃。
     コンポーネント側の固定高 24 箇所も `min-h-*` に置換した
2. **グリップアイコンによるパネル移動の実効化**
   - ヘッダー全体ではなく**グリップ（サイコロの 6）だけを `draggable`** にした。
     ヘッダー全体だと中のボタンやスライダーが掴めなくなるため
   - ドロップ先はヘッダー全体。`application/x-stoq-panel` を持つドラッグのときだけ
     枠が光り、離すと `layoutStore.movePanel` で配置が入れ替わる（localStorage に保存）
3. **フォントコントロールの移設**: 分析結果パネルのヘッダーから、
   画面右上「AI設定」ボタンの直下（`CommandBar`）へ移動
4. **フォント上限 28px ＋ アプリ全域適用**
   - `MAX_FONT_SIZE` を 20 → 28 に拡張
   - `:root` 自体に `font-size: var(--fs-base)` を設定し、**個別指定の無い要素も連動**させた
   - 固定 px クラス 84 箇所（メニューバー・タブ・サイドバー・資料チップ・トースト・
     モデル入力欄など）を `.t-body` / `.t-label` / `.t-heading` / `.t-mono` に置換
5. **検証**: `npm run verify`（typecheck → test → build）と `cargo test --lib` が全通過。
   フロント 64 件（うちドラッグ方向の意味を検証する新規テストを追加）/ Rust 35 件
