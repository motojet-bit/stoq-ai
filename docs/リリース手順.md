# リリース手順（自動更新の配信）

配信先: `motojet-bit/stoq-releases`
エンドポイント: `https://github.com/motojet-bit/stoq-releases/releases/latest/download/latest.json`

---

## 0. 一度だけ: 署名鍵

更新は**署名を検証してから適用される**。鍵は生成済み。

| もの | 置き場所 |
| --- | --- |
| 秘密鍵 | `~/.stoq-updater/stoq.key`（**リポジトリ外**） |
| 公開鍵 | 同ディレクトリの `stoq.key.pub`、および `tauri.conf.json` の `plugins.updater.pubkey` |

> **この秘密鍵を失うと、すでに配布した版へ更新を届けられなくなる。**
> 公開鍵はインストール済みのアプリに焼き込まれているため、別の鍵で署名し直しても
> 検証に通らない。パスワード付きの保管場所へ必ず控えを取ること。
>
> 鍵はパスワード無しで作ってある。パスワードを付け直したい場合は
> `npx tauri signer generate` からやり直し、`pubkey` も差し替える（＝旧版は更新不可になる）。

---

## 1. バージョンを上げる

`package.json` と `src-tauri/tauri.conf.json` の `version` を**同じ値**にする
（ずれると `appMeta.test.ts` が落ちる）。

---

## 2. ビルド（署名付き）

```bash
export TAURI_SIGNING_PRIVATE_KEY="$(cat ~/.stoq-updater/stoq.key)"
export TAURI_SIGNING_PRIVATE_KEY_PASSWORD=""
npm run tauri build
```

**`TAURI_SIGNING_PRIVATE_KEY` は鍵の「中身」を渡す。**
`..._PATH` だけでは署名されず、`.sig` が作られないまま終わる
（インストーラーはできるので気づきにくい）。

成功すると最後にこう出る:

```
Finished 2 updater signatures at:
    ...\bundle\msi\....msi.sig
    ...\bundle\nsis\..._x64-setup.exe.sig
```

---

## 3. `latest.json` を作る

```bash
npm run release:manifest
```

`dist-release/` に次の 2 つができる。

- `latest.json` — バージョン・署名・ダウンロード URL
- `StoQ AI Analyzer_<version>_x64-setup.exe` — 配布するインストーラー

`dist-release/` は `.gitignore` 済み。リポジトリには入れない。

---

## 4. GitHub Releases へ上げる

1. `stoq-releases` に **タグ `v<version>`**（例 `v0.2.0`）でリリースを作る
   `latest.json` の `url` がこのタグを指しているので、**タグ名がずれると 404 になる**
2. `dist-release/` の 2 ファイルを添付する
3. **Latest release** に設定する
   エンドポイントが `/releases/latest/download/latest.json` なので、
   ここが最新でないと配信されない

リリースノートを載せたい場合は、手順 3 の前に環境変数で渡す:

```bash
RELEASE_NOTES="不具合修正とパフォーマンス改善" npm run release:manifest
```

---

## 5. 確認

1. 1 つ前のバージョンをインストールして起動する
2. 数秒で「🎉 新しいバージョン（vX.X.X）が利用可能です」が出る
3. 「ダウンロードして更新」→ 進捗 →「再起動」で新しい版になる

出ないときに見るところ:

- `latest.json` の `version` が、インストール済みの版より**大きい**か
  （同じか小さいと出ない。`isNewer` がそう判定する）
- リリースが **Latest** になっているか
- `url` のタグ名と実際のタグが一致しているか
- 設定 →「一般」→「更新プログラムを確認」を押すと、失敗の理由が画面に出る

---

## 対応プラットフォーム

いまは **Windows (x86_64)** のみ。
macOS / Linux を足すときは `scripts/make-latest-json.mjs` の `TARGETS` に
`darwin-aarch64` などの行を追加する（成果物の探し方だけを足せばよい）。
