# API 調査メモ

外部 API の仕様・制限・注意点をここに集約する。

## Yahoo Finance

- 公式の一般公開 API は存在せず、非公式エンドポイントまたはサードパーティライブラリを使うのが一般的。
- レート制限・利用規約の確認が必要。
- ⬜ 調査未実施

## SEC EDGAR

- 公式 API（`data.sec.gov`）が提供されており、利用は無料。
- **User-Agent ヘッダに連絡先の明示が必須**（明示しないとブロックされる）。
- レート制限: 10 リクエスト/秒 が目安。
