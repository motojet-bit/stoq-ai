# StockAnalyzer — 米国株スクリーナー

米国株の銘柄を、公開データと**ユーザー独自の一次資料**の両面から評価するスクリーナー。
LLM が企業の将来性を評価し、スクリーニング結果に反映することを目指す。

## コンセプト

| 情報源 | 内容 |
| --- | --- |
| Yahoo Finance API | 株価・時系列・バリュエーション・財務指標などの定量データ |
| SEC (EDGAR) API | 10-K / 10-Q / 8-K などの法定開示 |
| ユーザー投入の一次資料 | 決算資料、決算プレゼン、カンファレンスコール書き起こし等 |
| LLM 評価 | 上記を統合し、企業の将来性を定性・定量の両面で評価 |
