Version 0.9.13バージョン 0.9.13

Quit from the menu now works, and filings are easier to bring in.メニューの「終了」と、決算資料の取り込みを改良しました。

Last updated: 2026-09-06最終更新日: 2026-09-06

What changed変更点

Quit from the menu now works — File → Quit closes the app as expected.

メニューの「終了」で閉じられるようになりました — ファイル → 終了 が効きます。

Bringing in filings is easier — for EDINET filings, paste the document ID (for example S100ABCD) into the document drop area and the original PDF is fetched for you.

決算資料の取り込みを改良しました — EDINET の書類なら、書類 ID（例: S100ABCD）を資料のドロップ欄に貼るだけで、原本の PDF を取り込めます。

Clearer guidance when a PDF has no text — a PDF re-saved through Print to PDF loses its text layer, so the message now says to fetch the original instead.

資料からテキストを読み取れないときの案内を改良しました — 印刷（PDF に保存）で作り直した PDF は文字が失われるため、配布元の原本を取り直すようご案内します。

ライセンスキー・保存済みの分析・メモ・設定はそのままです。
