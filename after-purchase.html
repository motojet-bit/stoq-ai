    Copy and paste from the e-mail メールからコピー＆ペースト

1 Open the e-mailメールを確認する

When the payment goes through, SendOwl (noreply@sendowl.com) sends an order e-mail to the address you used at checkout. It normally arrives within a few minutes.

決済が完了すると、SendOwl（noreply@sendowl.com）から ご購入時のメールアドレス宛に注文メールが届きます。通常は数分以内です。

Two things in it matter:

見るところは 2 つです。

  • ● The download link — this is where the installer (.exe) comes from. ダウンロードリンク —— インストーラー（.exe）はここから取得します。
  • ● The licence key — a string starting with V and a number (V1- for the current version). You enter it once, inside the app. ライセンスキー —— V＋数字で始まる文字列です （現行版は V1-）。アプリ内で一度だけ入力します。

You can also download straight after checkout 購入直後の画面からもダウンロードできます

The page shown right after payment has the same download button and licence key. That page expires 24 hours after purchase, so if you plan to install later, use the link in the e-mail instead.

決済直後に表示されるページにも、同じダウンロードボタンとライセンスキーがあります。 このページは購入から 24 時間で期限切れになりますので、 あとで入れる場合はメールのリンクをお使いください。

No e-mail? Check your spam folder first, then check that the address you entered at checkout was correct. A separate receipt e-mail also arrives; the licence key is in the order e-mail, not the receipt. メールが届かないとき: まず迷惑メールフォルダをご確認ください。次に、決済時のメールアドレスに誤りがないかご確認ください。 領収メールも別に届きますが、ライセンスキーが入っているのは注文メールのほうです。

2 Download and installダウンロードして入れる

Download StoQ_AI_Analyzer_x64-setup.exe from the link, then double-click it.

リンクから StoQ_AI_Analyzer_x64-setup.exe をダウンロードし、 ダブルクリックで実行します。

Windows will show a warning. This is expected. Windows の警告画面が出ます。想定どおりです。

StoQ AI Analyzer is built by an individual developer and does not carry a commercial code-signing certificate, so Microsoft Defender SmartScreen shows “Windows protected your PC”. It does not mean anything is wrong with the file.

本アプリは個人開発のため、商用のコード署名証明書を付けていません。そのため Microsoft Defender SmartScreen が 「WindowsによってPCが保護されました」 と表示します。ファイルに問題があるという意味ではありません。

  1. 1. Click More info 1. 詳細情報（More info）をクリック

    Only “Don’t run” is visible at first. The run button appears after this. 最初は「実行しない」しか出ていません。押すと実行ボタンが現れます。

  2. 2. Click Run anyway 2. 実行（Run anyway）をクリック

After that, the installer runs normally. あとは通常どおりインストーラーが進みます。

3 Enter the licence keyライセンスキーを入れる

  1. 1. Start StoQ AI Analyzer. StoQ AI Analyzer を起動します。
  2. 2. Open Settings → Licence. 設定 → ライセンス認証 を開きます。
  3. 3. Paste the key from the e-mail (V1-XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX — the leading number is the version generation). メールに記載のキー （V1-XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX。 先頭の数字は世代を表します）をコピー＆ペーストで入力します。
  4. 4. Press Activate. When it says the licence is valid, you are done. ライセンス有効化 を押します。 「ライセンスは有効です」と表示されれば完了です。
Your key is never sent anywhere. It is checked on your own PC, so activation works even without an internet connection. キーはどこへも送信されません。 確認はお客様の PC の中で行われるため、インターネットに繋がっていなくても有効化できます。

Getting started with the appアプリの使いはじめ

The app carries its own walkthrough. Open Help → Getting started (tutorial) from the menu bar and step through it — it covers the three things you need before your first analysis.

アプリの中にチュートリアルが入っています。メニューバーの ヘルプ → はじめかた（チュートリアル） を開いて順に進めてください。最初の分析を実行する前に必要な 3 点がまとまっています。

An API key is required. The app calls the AI provider you choose (OpenAI, Anthropic, Google, or a local model via Ollama) with your own key, so the usage is billed to you directly and nothing passes through us. Help → Setting up API keys walks through it. APIキーの登録が必要です。 本アプリは、お客様ご自身のキーで AI 提供元（OpenAI / Anthropic / Google、 または Ollama によるローカルモデル）を呼び出します。利用料は各社から直接請求され、 当方を経由しません。ヘルプ → APIキーの設定 に手順があります。

If something does not workうまくいかないとき

The licence key is rejected ライセンスキーが通りません

  • • Check for a stray space before or after the key. Copy and paste rather than typing it. キーの前後に余計な空白が入っていないかご確認ください。手入力ではなくコピー＆ペーストを推奨します。
  • • The key starts with V and a number (V1-). Make sure that part was included in the selection. キーは V＋数字 （V1- など）から始まります。 その部分まで選択できているかご確認ください。

I want to use it on another PC 別の PC で使いたい

Keep the key. Install the app on the new PC and enter the same key. One licence covers up to two PCs belonging to you.

キーはそのまま保管してください。新しい PC にアプリを入れ、同じキーを入力すれば有効化できます。 1 つのライセンスは、ご本人がお使いになる 2 台までご利用いただけます。

How do updates work? アップデートはどうなりますか

Fixes and improvements ship as free updates. We e-mail the address you bought with when a new version is available.

不具合修正や改善は無料のアップデートとして提供します。 新しい版が出たら、ご購入時のメールアドレス宛にご案内をお送りします。

I want to remove it アンインストールしたい

Uninstall from Windows Settings as usual. Leave Delete the application data unticked to keep your saved analyses; tick it to remove everything.

Windows の設定から通常どおりアンインストールできます。 Delete the application data のチェックを外したままにすると 保存済みの分析は残ります。すべて消す場合はチェックを入れてください。
